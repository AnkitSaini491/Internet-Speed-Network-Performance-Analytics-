# Internet-Speed-Network-Performance-Analytics-
Python-based network performance analytics project analyzing download speed, upload speed, latency, signal strength, network types, providers, and connection quality
🌐 Internet Speed & Network Performance Analytics

A Python-based data analytics project designed to analyze internet speed and network performance using real-world-style network metrics.

📊 Project Overview

This project analyzes network performance using metrics such as:

- Download Speed (Mbps)
- Upload Speed (Mbps)
- Latency (ms)
- Signal Strength (dBm)
- Network Type
- Internet Provider
- Connection Quality

The analysis helps identify the best-performing network types and providers while tracking speed and latency trends.

🚀 Features

- Network performance analysis
- Download and upload speed comparison
- Provider-wise performance analysis
- 4G, 5G and Wi-Fi comparison
- Latency trend analysis
- Connection quality classification
- Data visualization using Matplotlib
- CSV dataset generation

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

📈 Key Analysis

The project generates visualizations for:

1. Average Download Speed by Network Type
2. Internet Speed by Provider
3. Network Latency Trend
4. Download & Upload Speed Trends
5. Connection Quality Distribution

⚙️ Installation

Clone the repository:

git clone https://github.com/yourusername/Internet-Speed-Network-Performance-Analytics.git

Move into the project directory:

cd Internet-Speed-Network-Performance-Analytics

Install dependencies:

pip install -r requirements.txt

Run the project:

python internet_network_performance.py
